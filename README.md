# RaceDay.P1

## System Description
RaceDay is a race management system designed to manage race events, organisers, participants, event categories, entries, and race results. The system will allow users to register and manage their profiles, while organisers can manage events and their related information.

## Roles
### Organiser

Organisers are responsible for managing race events. They can create and manage events, manage categories, view participant entries, and manage race results.

### Participant

Participants can register and log in to the system, manage their profiles, view available events and categories, enter events, and view their results.
